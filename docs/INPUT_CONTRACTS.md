# 입력 계약 — 0.2.2, 2026-10-07

이 문서는 6개 감사 결함을 수정하면서 강화한 계약이다. 합성 자료의 소프트웨어 검증 범위이며 실제 계측 성능 인증이 아니다.

## CSV / DataFrame

CSV는 UTF-8(선택적 BOM), 쉼표 구분, 첫 레코드 헤더, 표준 따옴표 형식을 쓴다. 헤더 양끝 공백을 제거하며 이름은 대소문자를 구분한다. 빈 이름, 같은 이름, 공백 제거 후 충돌은 pandas가 이름에 `.1`을 붙이기 전에 거절한다. 오류에는 파일·헤더 행·열 이름·1부터 시작하는 열 위치가 있다. `x`와 `x.1`은 서로 다른 명시적 이름이다. 임의 구분자·별도 names/header override는 지원하지 않는다.

직접 DataFrame은 고유하고 양끝 공백 없는 문자열 열 이름을 요구한다. CSV는 `cvd_cbd.io_utils.read_csv`로 읽어 검증을 유지한다. 이미 외부 파서가 `x.1`로 바꾼 열에서 원래 중복이 있었는지는 알아낼 수 없다. float round-trip 파서는 기록된 유효 숫자를 보존한다.

## JSON

활성 JSON 입력은 `cvd_cbd.json_utils`의 공통 파서를 사용한다. 같은 객체 안의 중복 키는 최상위·중첩·배열 내부 모두 거부하며, 유니코드 이스케이프 해석 후 같아지는 키도 중복이다. 서로 다른 객체의 같은 키는 허용한다. 정상 JSON 자료형·값과 기존 설정 검사는 유지한다. 설정, 저장 모델 메타데이터, 불확도, CSV의 관찰구간 JSON 및 검증 도구 입력에 적용한다. CLI는 입력 위치를 포함한 오류와 종료 코드 2를 반환하며 키 이름·값·JSON 전체 내용은 출력하지 않는다. 전체 workflow의 불확도 및 상사성에 쓰는 관찰구간 JSON은 결과 생성 전에 파싱한다.

## 픽셀 교정

`um_per_px`와 legacy `pixel_size_um`은 **µm/pixel의 단일 등방성 교정값**이다. 값은 유한하며 0보다 커야 한다. 0, 음수, NaN, ±Inf, bool, 복소수, 빈 값, 단위가 붙은 문자열을 거절한다. 평문 소수/지수 숫자 문자열은 허용한다. 축별 x/y 필드와 벡터 교정값은 지원하지 않아 명시적으로 거절한다. 사전에 검증된 등방성 교정으로 재표본화해야 한다.

manifest, 직접 타일 계산(평판 포함), 학습, 추론, 저장 모델 JSON 및 번들에 적용한다. StudyConfig/legacy Config에는 픽셀 필드가 없고 영상 표·모델 계약에서 관리한다. 저장 config에 미지원 교정키를 넣으면 unknown-key 오류다.

## 입력 추적

manifest는 기존 OM 픽셀 중복용 `content_sha256`와 별도로 OM·실제 연결 REF/DARK·선택적 mask·scale record·대응 SEM 증빙의 **파일 바이트 SHA-256**을 보존한다. 읽은 metadata CSV의 해시와 유효 StudyConfig의 정규 JSON 해시도 기록한다. 기존 해시 없는 manifest는 재생성해야 한다. 내용이 같은 경로에서 바뀌거나 설정이 달라지면 추출 전 거절하고, 실행 도중 변경도 성공 보고 전에 다시 검사한다.

`input_provenance.json`은 numerical_input, evidence_only, table_consulted를 구분한다. 파일 목록은 선택된 ROI의 실제 연결 파일만 포함한다. 읽은 CSV 전체를 해시했다는 사실은 모든 행·모든 참조 영상을 계산에 사용했다는 뜻이 아니다. end-to-end 실행에는 평판 성장·점도·수동 비교·존재하여 사용된 uncertainty.json과 설정 파일도 기록한다. API에는 유효 설정 스냅샷, CLI에는 설정 파일 해시까지 남는다. 증빙의 해시는 측정 진실성을 인증하지 않는다.

## SD·결측·상관·Monte Carlo

FE-SEM SC에는 top과 bot 각각의 `label_sd_nm`이 필수다. 누락, NaN, 무한대, 음수는 `ValueError`이며 `missing_uncertainty_policy=error`다. 실제로 제공한 SD=0은 허용한다. SD 없이 계산된 ML 예측에는 `SC_sd=null`/CSV 빈칸, `uncertainty_status=NOT_AVAILABLE`을 반환한다. 제외 관측은 NOT_EVALUATED다. 값이 0인 계측 불확도와 다르다.

상관 열 자체가 없으면 독립(rho=0) 가정을 보고서에 명시한다. 열이 있으면 양쪽 관측에 동일한 유한 값 [-1,1]이 필요하다. 유한성 검사를 통과한 뒤의 부동소수점 소거 오차만 처리한다.

평판 성장 회귀의 `thickness_sd_nm`은 열 자체를 생략할 수 있다. 이 경우 회귀 잔차로만 표준오차를 추정하며 `NOT_PROVIDED_RESIDUAL_ESTIMATE_ONLY`로 표시한다. 열을 제공했으면 모든 값이 유한 비음수여야 하며 전부 빈값인 열도 거절한다. 명시적 영 SD는 SUPPLIED_ZERO_SD다. 잔차 표준오차가 0인 완벽한 선형 적합은 실제 계측 불확도가 없다는 증거가 아니다. MC 공분산은 여전히 별도로 제공해야 한다.

`uncertainty.propagate`는 독립적으로 제공한 평균과 **전체 log 공분산**을 사용한다. 누락된 SD나 미평가 예측 오차를 자동으로 공분산 0으로 바꾸지 않는다. 공분산 생략, NaN/Inf, 음수 대각, 비대칭, 비양의 준정부호는 거절한다. 명시적 영 공분산은 사용자가 제공한 결정론적 가정으로 보고한다. 샘플 수·seed·온도·가정 설명도 검증한다.

## 활성/비활성 반응 파라미터

측벽 반응 둘레와 활성 끝단으로 필요한 재료를 결정한다. 비활성 재료의 G는 생략 가능하며 `parameter_status=NOT_APPLICABLE`이다. 이는 G의 측정 불확도가 0이라는 뜻이 아니다. 활성 G는 유한 양수 필수다. compact 입력에는 각 mean을 정확히 한 번 나열한 `covariance_order`와 같은 크기의 행렬을 제공한다.

과거 11개 NAMES 순서와 11×11 공분산도 지원한다. 이 경우 미사용 G=0도 허용하며 미사용 입력은 별도 표시한다. 미사용 차원은 조건부 고정이 아니라 주변화하여 제거한다. 반환 draws의 SC/AR 열은 활성·비활성 분기에서 동일하고 보고서가 적용 여부를 명시한다. 양의 정부호 기본 예제의 seeded sampling을 유지하며, 특이 공분산의 수치적 영 고유모드에는 작은 가짜 잡음을 넣지 않는다.

## 지표

단일 출력 `(n,)` 및 `(n,1)`을 1차원으로 정규화한다. 실측·예측 길이 동일, 유한 값 필수다. scalar, row vector `(1,n)`(n>1), 다중 출력, 불일치 길이는 거절한다. 그룹은 같은 길이의 1차원 유효 ID 배열이다. 빈 벡터는 관측수 0과 null 지표, 상수 타깃은 R²=null이다. |target|<1e-6 nm의 상대오차는 제외하고 n_relative를 기록한다. Legacy weighted 지표의 가중 추정대상은 유지한다.

## 유지한 과학적 계약

T=(I−DARK)/(REF−DARK), OD=−log10(T), CLAHE 텍스처 분리, 외부 조건 LOGO 및 내부 그룹 CV, fold 안의 X/y scaling을 유지한다. RF/KRR/SVR grid·선택 기준·합성 생성 관계를 조정하지 않는다. 물리 ODE·Robin 경계·SI 변환·반응면·실제 top/bot 관측창을 유지한다. 27점 legacy 설계, 36개 condition×AR 점, 4,000회 noise 반복은 서로 다른 단위다.
